v1.2 카카오톡 오픈채팅방 연동

2026. 09. 04

길드 카카오톡 오픈채팅방에서도 포근해용을 쓸 수 있습니다. 디스코드와 같은 캐릭터 정보를 카톡에 맞춘 양식으로 보여드리고, 보석 시세판·각인서 등락 조회도 함께 개선했습니다.

💬이렇게 씁니다

  • 방에서 커맨드는 / 또는 .으로 시작합니다 — /정보 블레상돈 .군장 닉네임 /시세 운명의 파괴석 .모험섬 /가토 .도움말
  • 초성 별칭에도 원하는 접두사를 붙이면 됩니다: /ㅂㅂㄱ 4000 .ㅈㅂ 닉네임 /ㅅㅅ 아이템. 9월 6일부터 분배금은 ㅂㅂㄱ 4000처럼 접두사 없이도 받습니다. 다른 초성과 ...처럼 커맨드가 아닌 대화에는 조용히 반응하지 않아요
  • 카톡 닉네임이 캐릭터명이면 닉네임 생략 — 디스코드의 서버 닉네임 규칙과 같습니다. 본명/캐릭명처럼 구분자가 섞인 닉은 추측하지 않으니 /등록 캐릭터명 한 번(해제는 /등록 해제)
  • 결과 끝의 "이어서 쓸 수 있어요" 아래에 다음에 칠 커맨드가 한 줄씩 적혀 있어요 — 디스코드의 버튼 대신입니다
  • 이미지는 미리보기 카드로 옵니다 — /정보 /캐릭터 같은 캐릭터 조회는 캐릭터 이미지 카드가 먼저, /체방은 차트 카드, [따봉 이모티콘은 이모티콘 카드. 카드 아래 본문이 이어서 나와요
  • 방 밖에서도 됩니다 — 봇 오픈프로필을 열어 1:1 채팅으로 물어보면 같은 답을 나만 볼 수 있어요

📖카톡에서 더 읽기 편하게

  • /정보 /팔찌 /랭킹 /체급을 카톡 전용 양식으로 정리했습니다. 항목을 구분하고 줄바꿈을 늘렸으며, 랭킹의 집계 기준과 주의사항은 순위보다 먼저 보여드려요
  • 방에는 후속 커맨드 안내까지 포함해 1,500자 이내로 보내고, 긴 결과에는 전체 보기 링크를 붙입니다. 링크를 누르면 생략된 본문까지 확인할 수 있어요
  • 전체 보기는 30분간 임시 보관되며 서버 재시작 시에도 만료됩니다. 만료되면 같은 커맨드를 다시 입력해 주세요. . 커맨드와 접두사 없는 ㅂㅂㄱ를 사용하려면 휴대전화 스크립트를 9월 6일 배포본으로 교체해야 합니다
  • 이 카톡 전용 양식 변경은 디스코드의 캐릭터·랭킹 출력에 영향을 주지 않습니다

💎/보석 — 시세판부터 캐릭터 조회까지

  • /보석만 입력하면 4티어 겁화·작열 10~7레벨 최저가를 한눈에 볼 수 있어요. /ㅄ과 기존 /ㅂㅅ으로도 사용할 수 있습니다
  • /보석 겁화 10처럼 종류와 레벨로 검색하거나, /보석 블레상돈으로 캐릭터가 착용한 보석을 확인할 수 있습니다. 디스코드 슬래시에서는 종류·레벨·닉네임 옵션을 선택해 주세요
  • 시세판은 5분 간격으로 갱신하며, 저장된 과거 가격이 있으면 등락을 함께 표시합니다. 수집 첫날처럼 비교 기록이 없으면 등락을 표시하지 않아요
  • 비교에 사용한 실제 기준일을 안내하고, 항목마다 기준일이 다르면 따로 표시합니다. /보석과 /보석현황에 요청이 동시에 몰려도 같은 조회를 공유하도록 안정화했습니다

📈각인서 랭킹 — 쪽 넘김과 가격 변동

  • /유각 2 /전각 2처럼 1~20쪽을 지정할 수 있습니다. 디스코드 슬래시에서는 페이지 옵션을 사용하며, /각인서랭킹에서도 같은 방식으로 조회합니다
  • /비싼유각을 /유각과 같은 커맨드로 사용할 수 있습니다. 디스코드 슬래시·.비싼유각, 카톡 /비싼유각·.비싼유각을 모두 지원합니다
  • 현재 가격과 전일 평균가 대비 등락을 함께 보여드립니다. 비교할 수 없는 경우에는 등락을 생략합니다
  • 1골드보다 작은 변화도 상승·하락을 구분하고, 아주 작은 차이는 0.01 미만으로 표시합니다. 실제 가격이 같을 때만 변동없음으로 나옵니다

⌨️9월 6일 추가 — 카톡 분배금 간편 입력

  • 카카오톡에서 ㅂㅂㄱ 4000처럼 슬래시 없이 분배금 계산을 실행할 수 있습니다. ㅂㅂㄱ 4000 8처럼 인원을 지정할 수도 있으며, 금액을 빼면 사용법을 안내합니다
  • 기존 /분배금·/ㅂㅂㄱ·.ㅂㅂㄱ와 계산값·출력은 같습니다. 다른 초성 명령에는 계속 / 또는 .을 붙여 주세요. 디스코드의 기존 입력 방식은 바뀌지 않습니다
  • 봇 운영자는 서버 배포와 휴대전화 스크립트 교체를 함께 적용해야 합니다. 스크립트의 기존 SERVER·ROOMS 설정을 유지한 뒤 컴파일·활성화해 주세요

⚖️9월 5일 수정 — 분배금 계산 기준 구분

  • /분배금과 /ㅂㅂㄱ에서 선점 추천 입찰가·균등 분배 입찰가·재판매 원금 회수 상한을 따로 보여드립니다. 기존의 균등 분배 금액을 추천가로 표시하던 혼동을 바로잡았습니다
  • 추천가는 균등 분배 기준값을 1.1로 나눈 금액입니다. 시세 46,664G 기준 추천가는 4인 30,225G · 8인 35,263G · 16인 37,781G입니다
  • 인원을 지정하면 해당 인원의 추천가와 균등 분배가만 남기고 공통 재판매 상한은 유지합니다. 반복되던 설명 세 줄은 결과에서 빼고 README와 홈페이지로 옮겼습니다. 재판매 상한은 판매 수수료 5%를 반영한 원금 회수 기준이며, 포기하는 분배금의 기회비용은 포함하지 않습니다
  • 계산 중 소수 오차 때문에 정수 결과가 1G 낮아지던 문제를 수정했습니다. 디스코드는 임베드, 카톡은 평문으로 표시하며 두 플랫폼의 계산값은 같습니다

🤝9월 5일 수정 — 시너지 안내와 치적 표시

  • /시너지 전체 목록을 계열별 직업·수치 안내로 바꿨습니다. 전태/고기와 질풍/이슬비를 나누고, 딜러 세팅한 서포터의 시너지도 별도로 표시합니다
  • 전태·딜러 바드·딜러 도화가의 방어력 감소 12%를 반영했습니다. 두동의 이동속도와 마엘스톰의 공속·이속은 현재 전투정보실 툴팁 기준을 유지하며, 적용 조건은 직업 검색 결과에서 확인할 수 있습니다
  • /시너지 전태 /시너지 블레처럼 빌드·직업 축약명으로도 검색할 수 있습니다. 기존 직업명·시너지 종류 검색도 그대로 지원합니다
  • 카카오톡 /치적·/ㅊㅈ에서는 사진 미리보기 링크를 보내지 않습니다. 치적 계산과 결과 본문, 디스코드 썸네일과 다른 명령어의 사진 카드는 그대로입니다

🛡️9월 5일 수정 — 조회와 알림 안정성 강화

  • /랭킹과 /체급을 25명씩 나누어 조회할 수 있습니다. 디스코드에서는 페이지 옵션과 이전·다음 버튼으로, 카톡에서는 전체 보기 링크로 긴 순위를 확인할 수 있어요
  • /딜지분은 관문 뒤의 단독 숫자를 시간으로 구분하고, 쉼표가 들어간 피해량과 초 단위 시간도 읽습니다. 잘못된 값을 입력하면 임의의 기본값으로 계산하지 않고 사용 예시를 안내합니다
  • /cpm의 목표 횟수를 경계값에서도 정확히 계산하고, /코어는 비슷한 이름을 추측하지 않고 정확히 일치하는 코어만 보여드립니다
  • 일시적인 조회 실패가 발생해도 기존 등록 정보와 저장 기록을 보존하며, 손상되거나 비어 있는 저장 파일은 안전하게 복구할 수 있도록 보관합니다
  • 모험섬과 업데이트 알림은 일부 채널 전송에 실패하면 실패한 채널과 공지만 다시 전송합니다. 재시작하더라도 남은 재시도를 이어서 처리합니다
  • 채널 제한 확인과 카톡의 긴 응답·오류 처리를 보강하고, 외부 계산 실패가 봇 전체 동작에 영향을 주지 않도록 실행 영역을 분리했습니다

🔀디스코드와 다른 점

  • /랭킹 /체급은 카톡에서도 됩니다 — 디스코드에서 /등록한 길드원과 카톡에서 /등록한 사람이 한 판에 들어가고, 어느 쪽에서 보든 같은 순위예요. 같은 캐릭터를 양쪽에 등록해도 한 번만 셉니다
  • /알림설정과 모험섬 아침 알림·업데이트 자동 알림은 디스코드 채널로만
  • 등록은 카톡 닉네임에 묶여요 — 닉네임을 바꾸면 /등록 다시. 디스코드 등록과는 별개지만, 닉네임이 캐릭터명이면 어느 쪽에서 물어도 같은 캐릭터가 나옵니다

⚙️어떻게 돌아가나

카카오 공식 챗봇은 오픈채팅방에 들어갈 수 없어서, 방에 참여한 봇 계정이 메시지를 받아 디스코드 봇과 같은 서버에 물어보고 답을 대신 올리는 방식입니다. 그래서 답이 봇 계정 이름으로 나가고, 봇 계정 기기가 꺼져 있으면 잠시 답이 없을 수 있어요. 커맨드는 /·., 이모티콘은 [로 시작하며, 분배금의 ㅂㅂㄱ만 접두사 없이도 받습니다. 그 외 일반 대화에는 반응하지 않습니다.

🎯그 외 — /치적이 더 정확해졌어요

  • 백어택 +10%는 기습의 대가를 낀 캐릭터만 합산 — 프론트·헤드 빌드는 이제 빠집니다
  • "추가 치명타 확률"에 아이덴티티(슬레이어 포식자 30% · 창술사 절정 난무 25% · 아르카나 재상 카드 20%), 파생 노드(기상술사 기민함 = 이속 40%×30% → 12%), 치적 시너지(급소 노출처럼 치명타 저항을 낮추는 트라이포드 — 기상술사 돌개바람, 배틀마스터 뇌명각·용맹의 포효, 아르카나·건슬링어 등)가 들어갑니다
  • 아크패시브 치적은 계열명이 아니라 효과 문장의 조건과 적용 범위로 나눕니다. 조건 없이 적용되는 깨어나는 힘·영혼친화력 등은 총합에 넣고, 광기 상태·피스메이커 스탠스·특정 스킬처럼 조건이 붙은 효과는 "추가 치명타 확률"로 분리합니다
  • 결과 아래 안내는 디스코드와 카톡 모두 "파티 시너지는 제외" 한 줄로 간소화했습니다. 백어택 합산 기준과 실제 계산 방식은 그대로입니다

🕳️그 외 — /지옥 /나락은 등급 필수

등급 없이 치면 기본값으로 뽑아 주던 것을 바꿔, 이제 /지옥 전설 /나락 5회처럼 등급(전설·영웅·희귀 또는 7회·6회·5회)을 꼭 넣어야 합니다. 빈 채로 치면 사용법이 나와요. 디스코드·카톡 공통.
