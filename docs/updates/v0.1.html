기본 커맨드 7종으로 시작해 하루 만에 캐릭터 조회 · 시세 · 게임 정보 커맨드를 갖췄고, Oracle Cloud 서버에서 24시간 돌기 시작했습니다.

  • 24시간 운영 — Oracle Cloud 서버 + pm2 자동 복구
  • 캐릭터 조회 전면 구축 — /캐릭터 /군장 /원정대 /전투력 + 부위별 상세 10종 (/장비 /악세 /스톤 /팔찌 /스킬 /앜패 /앜그 /아바타 /내실 /낙원력)
  • 시세 · 정보 커맨드 — /시세 /보석 /보석현황 /장착보석 /각인서 /각인서랭킹 /생활재료 /이벤트 /공지
  • 게임 정보 커맨드 — /클골 /주급 /시너지 /체방 /지옥 /나락 /효율(전 티어 × 0~10단계 실시간 시세) /연마표 /코어(558종) /가토 /분배금
  • 게임 호환 /스킬코드 — 게임 [K] 스킬 창에 붙여넣는 진짜 스킬코드 발급
  • 이모티콘 시스템 — 채팅 [키워드 입력 시 이미지 응답 (74종), /이모티콘 목록
  • 채팅 커맨드 — 초성 바로 입력(ㅂㅂㄱ 4000), 단어는 점 필수(.분배금), 슬래시 별칭(/ㅂㅂㄱ) 23종
  • 모험섬 아침 알림 — 매일 아침 8시(KST) 자동 공지, 서버별 설정(/알림설정)
  • 공개 봇 전환 · 홈페이지 오픈 — 어느 서버든 초대 가능, GitHub 공개 + MIT 라이선스
