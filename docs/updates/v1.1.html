길드원끼리 비교하는 랭킹 두 종이 들어왔고, 수요일 업데이트 공지가 자동으로 채널에 올라옵니다. 이모티콘은 160종으로 늘었어요.

🏆/랭킹 — 길드 내 스펙 랭킹

이 서버에 /등록한 길드원끼리 스펙 순위를 봅니다. 기준은 로펙의 달성 최고 점수 — 로펙이 기억하는 그 캐릭터의 최고 환산 점수라, 악세·보석을 다른 캐릭에 옮겨 둔 사이에도 순위가 내려가지 않습니다.

  • 줄마다 최고 점수 · 같은 레벨 중앙값 대비 ± · 직업 순위와 상위 %를 함께 표시
  • 점수 스케일이 다른 서포터는 딜러와 따로 묶어서 보여줍니다
  • 내 줄에는 ← 나 표시 · 채팅은 ㄹㅋ

📊/체급 — 원정대 체급 랭킹

1720 이상 캐릭터 전부의 로펙 환산 점수를 합산해 계정 체급을 비교합니다. 본캐 하나만 센 사람보다 여러 캐릭을 키우고 각각 세팅까지 맞춘 사람이 위로 올라가요.

  • 환산 점수라 서포터를 많이 키운 분도 딜러와 같은 척도로 계산됩니다 (전투력은 서폿이 구조적으로 낮아 쓰지 않았어요)
  • 줄마다 로펙 합 · 1720↑ 캐릭 수(딜/폿) · 평균 · 템렙 합
  • /랭킹과 /체급은 결과 아래 버튼으로 서로 이동 · 채팅은 ㅊㄱ

로펙에 아직 없는 캐릭터는 "조회 안 됨"으로 따로 표시돼요. lopec.kr에서 한 번 검색(갱신)하면 다음부터 집계됩니다.

🔔업데이트 공지 자동 알림

매주 수요일 업데이트 내역이 공식 공지에 올라오면 3분 안에 /업데이트 화면이 알림 채널로 자동 발송됩니다. 정해진 시각이 아니라 실제 게시 시점을 기준으로 하기 때문에 점검이 연장돼도 그때 맞춰 나가고, 점검 연장 공지가 따로 올라오면 그것도 알려드려요.

  • 직접 볼 때는 /업데이트 또는 /업뎃 · 채팅은 ㅇㄷㅇㅌ / .업뎃
  • 알림을 받을 채널은 서버 관리자가 /알림설정 켜기로 지정 (모험섬 아침 알림과 같은 채널)

⏱/cpm — 분당 시전 횟수

스킬 시전 횟수와 시간을 넣으면 CPM(Casts Per Minute)과 평균 시전 간격을 계산합니다. 목표 CPM을 함께 넣으면 몇 번 더 눌러야 하는지도 알려줘요. 예: .cpm 35 7분
