개인정보 처리 안내

포근해 길드가 운영하는 포근해용 홈페이지의 소셜 로그인과 길드 가입에 관한 안내입니다. 홈페이지 안내와 커맨드 목록은 로그인 없이 이용하실 수 있습니다.

수집하는 정보와 목적

디스코드 또는 카카오로 처음 로그인하면 해당 서비스의 고유 계정 ID와 표시 이름(닉네임), 가입·로그인 시각을 저장합니다. 이 정보는 같은 회원을 확인하고 계정 화면과 로그인 기능을 제공하는 데 사용합니다. 표시 이름은 다시 로그인할 때 갱신합니다.

이메일·프로필 사진·친구 목록은 저장하지 않습니다. 외부 서비스의 접근 토큰은 로그인 정보를 확인할 때만 사용하며 저장하지 않습니다. 두 서비스의 계정을 닉네임이나 이메일로 합치지 않습니다.

길드 가입을 신청하면 대표 캐릭터명, 신청·심사 시각, 신청·승인 상태와 관리 권한을 함께 저장합니다. 길드 관리자는 가입 심사와 일정 열람 권한 관리를 위해 로그인 서비스, 표시 이름, 대표 캐릭터명과 신청 상태를 확인합니다. 최고관리자는 승인 회원에게 관리자 권한을 부여하거나 회수할 수 있습니다.

게임에서 해당 캐릭터가 보낸 번호를 관리자가 확인할 수 있도록 일회용 인증번호, 발급·만료 시각과 잘못 입력한 횟수를 임시 보관합니다. 번호는 신청자에게만 표시하며 관리자는 게임에서 받은 번호를 입력합니다. 인증번호는 30분 후 사용할 수 없고 정기 정리 때 삭제하며, 재발급하면 교체하고 심사 완료·탈퇴 때도 삭제합니다. 게임 채팅 내용이나 게임 계정 비밀번호는 수집하지 않습니다.

디스코드 자동 승인을 선택하면 추가 동의를 받아 KOR Lost ARK 서버의 역할과 서버 별명을 조회합니다. 인증된 대표 캐릭터명이 신청 이름과 같은지 확인하고, 로스트아크 공식 API에서 캐릭터명·서버명·길드명을 조회해 루페온 서버의 포근해 소속인지 확인합니다. 조회 결과와 접근 토큰은 승인 판단에만 사용하며 별도로 저장하지 않습니다. 승인된 신청 상태와 캐릭터명은 위 길드 정보에 남습니다.

추가 동의를 신청한 회원과 연결하기 위해 회원·현재 로그인 세션·신청 번호와 캐릭터명에 묶인 임시 확인 정보를 최대 5분 동안 사용하고, 사용하거나 만료되면 삭제합니다. 관리자 거절·열람 철회 후 자동 승인으로 재진입하지 않도록 수동 심사가 필요하다는 표시를 회원 탈퇴 전까지 보관합니다. 카카오 회원은 기존 게임 내 번호 확인으로 신청합니다.

보관 기간과 삭제

회원 정보는 회원 탈퇴 전까지 보관합니다. 내 계정에서 회원 탈퇴를 선택하면 이 홈페이지의 회원 정보, 길드 가입 신청·승인 상태·관리자 권한과 모든 로그인 세션을 삭제합니다. 본인 확인을 위해 최근 5분 이내 로그인이 필요합니다. 다시 가입하면 길드 승인을 새로 받아야 합니다.

카카오로 가입한 회원이 탈퇴하면 카카오와 포근해용의 연결도 해제합니다. 카카오에서 직접 연결을 해제하면 전달받은 연결 해제 알림에 따라 홈페이지 회원 정보를 삭제합니다. 연결 해제 처리 도중 오류가 발생하면 처리를 마치는 데 필요한 계정 ID와 요청 정보를 일시 보관하고, 재시도 완료 후 삭제합니다. 처리가 끝날 때까지 해당 홈페이지 계정의 로그인과 이용은 제한됩니다.

카카오 연결 해제로 홈페이지 회원 정보를 삭제할 때도 길드 가입 신청·승인 상태·관리자 권한을 함께 삭제합니다.

회원 탈퇴나 카카오 연결 해제로 회원 정보를 삭제하면 남아 있는 자동 승인 확인 정보와 수동 심사 표시도 함께 삭제합니다.

디스코드·카카오의 원래 계정, 디스코드 서버 가입 상태와 봇의 출석·캐릭터 등록 기록은 홈페이지 탈퇴로 변경되지 않습니다. 홈페이지와 봇의 기존 기록은 별도로 관리합니다.

길드 일정 열람

길드 승인을 받은 회원과 운영자는 홈페이지에서 Google 스프레드시트의 읽기 전용 미리보기를 열 수 있습니다. 시트를 열면 Google에 연결되며 해당 서비스의 개인정보 처리방침이 적용됩니다. 원본 Google 시트의 공유 설정은 유지되므로 홈페이지의 승인·열람 철회가 원본 링크의 공개 범위나 이미 열린 외부 창의 접근까지 바꾸지는 않습니다.

로그인 쿠키와 접속 제한

로그인 유지 쿠키는 7일 뒤 만료되며, 로그인 진행을 확인하는 쿠키는 5분 뒤 만료됩니다. 쿠키의 비밀값은 서버에 해시로 저장하고 만료된 인증 정보는 주기적으로 정리합니다. 광고나 분석용 쿠키는 사용하지 않습니다.

과도한 로그인 요청을 제한하기 위해 접속 IP별 요청 횟수를 서버 메모리에 10분 단위로 임시 보관하고 만료된 항목은 매분 정리합니다. 이 정보는 회원 프로필에 저장하지 않습니다. 인증 요청 주소·로그인 코드·쿠키·비밀키를 접속 로그에 남기지 않습니다.

외부 로그인 서비스

로그인할 때 선택한 서비스의 인증 화면으로 이동합니다. 해당 서비스의 계정 처리에는 각 서비스의 개인정보 처리방침이 적용됩니다. 홈페이지의 로그인 정보는 Oracle Cloud 서버에서 보관하며 마케팅이나 광고에 이용하지 않습니다.

서버 보관 위치

홈페이지 회원 정보는 Oracle Cloud 일본 오사카 리전(ap-osaka-1)의 서버에 보관합니다. 로그인·회원 관리 요청 시 암호화된 통신으로 위 수집 항목과 인증 유지 정보를 전송하고, 로그인 서비스 제공과 보관을 위해 처리합니다. 각 정보의 보관 기간과 삭제 방법은 위 안내와 같습니다.

서버 제공자: Oracle Corporation. 제공자의 개인정보 처리 및 연락 창구는 Oracle 서비스 개인정보 처리방침에서 확인할 수 있습니다. 홈페이지의 정보 처리·삭제 문의는 아래 운영 연락처로 보내 주세요.

국외 서버 보관을 원하지 않으시면 로그인하지 않고 공개 안내를 이용하실 수 있습니다. 가입 후에는 회원 탈퇴 또는 삭제 문의를 통해 정보 보관을 중단할 수 있으며, 이 경우 계정 기능은 이용할 수 없습니다.
