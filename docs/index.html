내 서버에 부르기

포근해 길드 전용으로 만들었지만, 어느 디스코드 서버에서든 쓸 수 있어요. 설치할 것도 로그인할 것도 없습니다.

＋ 서버에 초대하기 디스코드 로그인 상태에서 서버를 고르면 끝이에요.
  1. 1

    봇 초대

    위 버튼을 눌러 서버를 선택합니다. 메시지 보내기 · 링크 임베드 · 파일 첨부 — 응답과 이모티콘을 올리는 데 필요한 최소 권한만 요청해요. (서버 관리 권한이 있어야 합니다)

  2. 2

    쓸 채널 정하기 선택

    특정 채널에서만 커맨드를 허용하려면 서버 설정 → 연동 → 포근해용에서 채널을 제한하세요. 이모티콘은 제한과 무관하게 어디서든 됩니다.

  3. 3

    알림 켜기

    관리자가 원하는 채널에서 /알림설정 켜기 한 번. 매일 아침 8시 모험 섬과 수요일 업데이트 내역이 그 채널로 갑니다.

  4. 4

    각자 캐릭터 등록

    길드원이 /등록 하면 닉네임 없이 조회할 수 있고, /랭킹 /체급에도 올라갑니다. /도움말로 전체 커맨드를 볼 수 있어요.

카카오톡 연동준비 중

길드 카카오톡 채팅방에서도 캐릭터 조회와 시세 검색 같은 핵심 기능을 쓸 수 있도록 준비하고 있어요. 디스코드 봇과 같은 두뇌(로스트아크 공식 API)를 공유해서, 어느 쪽에서 물어봐도 같은 정보를 받게 됩니다. 자세한 사용법은 준비가 끝나면 이곳에 공개할게요.

직접 띄우기
