포근해용

포근해 길드 전용 로스트아크 챗봇 — 캐릭터부터 시세, 모험섬 알림, 이모티콘까지

버전 v1.0 커맨드 51개 이모티콘 74종 가동률 24시간 데이터 로스트아크 공식 API

✨주요 기능

루페온 서버 포근해 길드를 위해 만든 디스코드 봇이에요. 슬래시(/) 하나로 게임 정보를 채팅방에서 바로 확인하세요.

🙋 내 캐릭터 등록

/등록 한 번이면 이후 모든 조회 커맨드에서 닉네임을 생략할 수 있어요. 서버 닉네임이 캐릭터명이면 등록 없이도 바로 됩니다.

🔍 캐릭터 조회

기본 정보부터 장비·각인·보석·카드 군장검사, 원정대 전체 캐릭터까지.

📋 부위별 상세

장비 품질, 악세서리 연마 효과, 스톤 세공, 팔찌, 스킬 트라이포드·룬.

✨ 최신 시스템

아크 패시브 포인트·노드, 아크 그리드 코어, 전투력, 수집품 내실.

💰 시세 · 계산

거래소 검색, 보석 최저가, 경매 적정 입찰가 자동 계산 (수수료 반영).

🏝️ 모험섬 알림

매일 아침 8시, 오늘의 모험 섬과 보상을 자동 공지. 골드섬은 💰 표시.

😄이모티콘 사용법

커맨드가 아니라 일반 채팅으로 입력해요. 어느 채널에서든 작동합니다.

  1. 채팅에 [키워드 입력

    예: [따봉 [ㅋㅋ [모무룩 [엣큥 — 봇이 해당 이모티콘 이미지를 올려줍니다.

  2. 키워드 목록 확인

    아래 목록을 펼쳐 보거나, 서버에서 /이모티콘 커맨드를 입력하면 전체 키워드를 볼 수 있어요.

💡 이모티콘은 커맨드 채널 제한과 무관하게 서버의 모든 채널에서 사용할 수 있어요.

🔗디스코드 서버에 초대하기

포근해 길드용으로 만들었지만, 버튼 하나로 다른 서버에도 추가할 수 있어요.

➕ 포근해용 초대하기
  1. 버튼 클릭 → 서버 선택

    디스코드에 로그인한 뒤 봇을 추가할 서버를 고릅니다. (서버 관리 권한이 있어야 해요)

  2. 권한 승인

    메시지 보내기 · 링크 임베드 · 파일 첨부 — 봇이 응답과 이모티콘을 올리는 데 필요한 최소 권한만 요청합니다.

  3. 바로 사용

    /도움말을 입력해 보세요. 이모티콘([따봉)도 바로 작동합니다.

💡 특정 채널에서만 커맨드를 허용하고 싶다면 서버 설정 → 연동 → 포근해용에서 채널을 제한할 수 있어요. 모험섬 아침 알림은 서버 관리자가 /알림설정 켜기로 원하는 채널에 켤 수 있습니다.

💬카카오톡 연동준비 중

카카오톡에서도 포근해용을

길드 카카오톡 채팅방에서도 캐릭터 조회, 시세 검색 같은 핵심 기능을 쓸 수 있도록 연동을 준비하고 있어요. 디스코드 봇과 같은 두뇌(로스트아크 공식 API)를 공유하는 방식이라, 어느 쪽에서 물어봐도 같은 정보를 받아볼 수 있게 됩니다. 자세한 사용법은 준비가 끝나면 이곳에 공개할게요.
