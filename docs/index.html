커맨드 19개 이모티콘 74종 가동률 24시간 데이터 로스트아크 공식 API

✨주요 기능

슬래시(/) 하나로 게임 정보를 채팅방에서 바로 확인하세요.

🔍 캐릭터 조회

기본 정보부터 장비·각인·보석·카드 군장검사, 원정대 전체 캐릭터까지.

📋 부위별 상세

장비 품질, 악세서리 연마 효과, 스톤 세공, 팔찌, 스킬 트라이포드·룬.

✨ 최신 시스템

아크 패시브 포인트·노드, 아크 그리드 코어, 전투력, 수집품 내실.

💰 시세 · 계산

거래소 검색, 보석 최저가, 경매 적정 입찰가 자동 계산 (수수료 반영).

🏝️ 모험섬 알림

매일 아침 8시, 오늘의 모험 섬과 보상을 자동 공지. 골드섬은 💰 표시.

😄 이모티콘

채팅에 [따봉처럼 입력하면 이미지로 응답. 모든 채널에서 사용 가능.

⌨️커맨드 목록

서버에서 /도움말을 입력하면 언제든 다시 볼 수 있어요.

/도움말커맨드 사용법 안내

😄이모티콘 사용법

커맨드가 아니라 일반 채팅으로 입력해요. 어느 채널에서든 작동합니다.

  1. 채팅에 [키워드 입력

    예: [따봉 [ㅋㅋ [모무룩 [엣큥 — 봇이 해당 이모티콘 이미지를 올려줍니다.

  2. 키워드 목록 확인

    /이모티콘 커맨드를 입력하면 사용 가능한 전체 키워드(74종)를 볼 수 있어요.

🔗연동 방법

현재는 비공개로 운영 중인 봇이라 지정된 서버에서만 사용할 수 있어요. 직접 운영하고 싶다면 아래 방법으로 나만의 봇을 띄울 수 있습니다.

  1. 코드 받기

    GitHub 저장소를 클론합니다. Node.js 24 이상이 필요해요.

    git clone https://github.com/ju00moon-sketch/opentalk-lostark-bot.git
cd opentalk-lostark-bot
npm install
  2. 토큰 3개 발급

    디스코드 개발자 포털에서 봇 토큰과 애플리케이션 ID, 로스트아크 개발자 사이트에서 API 키를 발급받아 .env 파일에 넣습니다. 자세한 과정은 저장소 README에 단계별로 정리돼 있어요.

  3. 커맨드 등록 후 실행 
    npm run register
npm start

    "로그인 완료"가 뜨면 디스코드에서 /도움말을 입력해 보세요.

💡 24시간 운영하려면 무료 클라우드(Oracle Cloud Free Tier 등)에 올리고 pm2로 상시 실행하는 걸 추천해요. 이 봇도 그렇게 돌아가고 있습니다.
