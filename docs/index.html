🌱

포근해챗봇

로스트아크 정보 조회 디스코드 봇 — 캐릭터부터 시세, 모험섬 알림, 이모티콘까지

커맨드 19개 이모티콘 74종 가동률 24시간 데이터 로스트아크 공식 API

✨주요 기능

슬래시(/) 하나로 게임 정보를 채팅방에서 바로 확인하세요.

🔍 캐릭터 조회

기본 정보부터 장비·각인·보석·카드 군장검사, 원정대 전체 캐릭터까지.

📋 부위별 상세

장비 품질, 악세서리 연마 효과, 스톤 세공, 팔찌, 스킬 트라이포드·룬.

✨ 최신 시스템

아크 패시브 포인트·노드, 아크 그리드 코어, 전투력, 수집품 내실.

💰 시세 · 계산

거래소 검색, 보석 최저가, 경매 적정 입찰가 자동 계산 (수수료 반영).

🏝️ 모험섬 알림

매일 아침 8시, 오늘의 모험 섬과 보상을 자동 공지. 골드섬은 💰 표시.

😄 이모티콘

채팅에 [따봉처럼 입력하면 이미지로 응답. 모든 채널에서 사용 가능.

⌨️커맨드 목록

서버에서 /도움말을 입력하면 언제든 다시 볼 수 있어요.

커맨드기능
/캐릭터 닉네임서버 · 직업 · 아이템 레벨 등 기본 정보
/군장 닉네임장비 · 각인 · 보석 · 카드 한눈에
/전투력 닉네임전투력 · 전투 특성 · 공격력/생명력
/원정대 닉네임계정의 모든 캐릭터를 아이템 레벨 순으로
/장비 /악세 /스톤 /팔찌부위별 상세 — 품질, 연마 효과, 세공 각인, 팔찌 효과
/스킬 닉네임채용 스킬 · 트라이포드 · 룬
/앜패 /앜그아크 패시브 포인트/노드 · 아크 그리드 코어/효과
/아바타 닉네임장착 아바타 목록
/내실 닉네임수집품 진행도 (모코코 씨앗, 섬의 마음 등)
/시세 아이템명거래소 가격 검색 (부분 검색 가능)
/보석 종류 레벨경매장 보석 최저가 (겁화/작열/광휘/멸화/홍염)
/입찰 가격 [인원]경매 적정 입찰가 계산 (4/8/16인, 수수료 5% 반영)
/모험섬오늘의 모험 섬 시간표 + 주요 보상
/이모티콘사용 가능한 이모티콘 키워드 목록
/도움말커맨드 사용법 안내

😄이모티콘 사용법

커맨드가 아니라 일반 채팅으로 입력해요. 어느 채널에서든 작동합니다.

  1. 채팅에 [키워드 입력

    예: [따봉 [ㅋㅋ [모무룩 [엣큥 — 봇이 해당 이모티콘 이미지를 올려줍니다.

  2. 키워드 목록 확인

    /이모티콘 커맨드를 입력하면 사용 가능한 전체 키워드(74종)를 볼 수 있어요.

🔗서버에 초대하기

버튼 하나로 여러분의 디스코드 서버에 포근해챗봇을 추가할 수 있어요.

➕ 포근해챗봇 초대하기
  1. 버튼 클릭 → 서버 선택

    디스코드에 로그인한 뒤 봇을 추가할 서버를 고릅니다. (서버 관리 권한이 있어야 해요)

  2. 권한 승인

    메시지 보내기 · 링크 임베드 · 파일 첨부 — 봇이 응답과 이모티콘을 올리는 데 필요한 최소 권한만 요청합니다.

  3. 바로 사용

    /도움말을 입력해 보세요. 이모티콘([따봉)도 바로 작동합니다.

💡 특정 채널에서만 커맨드를 허용하고 싶다면 서버 설정 → 연동 → 포근해챗봇에서 채널을 제한할 수 있어요. 모험섬 아침 알림은 현재 운영 서버 전용이며, 초대한 서버에서의 알림 설정 기능은 준비 중입니다.
직접 운영하고 싶다면 (셀프 호스팅)

코드가 공개돼 있어서 나만의 봇을 띄울 수도 있어요. Node.js 24 이상 필요.

cd opentalk-lostark-bot
npm install
