# 스펙업 효율 `/스펙업` 구현 계획

> 각 작업의 구현과 검증을 순서대로 진행하고 체크박스(`- [ ]`)로 완료 여부를 기록한다.

**Goal:** `/스펙업 [닉네임]`이 로펙 스펙업 가이드와 같은 후보·같은 점수를 내고, 기대 비용은 공식 경매장·거래소 API 실시간 시세로 계산해
`점수/10만G` 순위 상위 10개를 디스코드 임베드와 카톡 평문으로 보여 준다.

**Architecture:** 코어 `lopec-sim.getSpecupGuide(닉)`이 로펙 계산 모듈을 격리 프로세스에서 실행하고(시세는 호스트가 `specup-prices.js`로 모아 주입)
정규화된 `SpecupGuide`를 돌려준다. 표시 계층 `specup-view.js`(순수 함수)가 그것을 디스코드 본문·카톡 미리보기·카톡 전체 평문으로 바꾸고,
`commands/specup.js`는 캐릭터 존재 확인 → 코어 호출 → 렌더링만 한다. 카톡 미리보기(10개)와 전체 보기(전체 행)를 나누기 위해 브리지에
`kakaoFull` 훅을 더한다. 기술 담당(코어)과 기획 담당(표시·명령·훅)이 서로 다른 파일·브랜치에서 병행하고, 경계는 4절 계약 하나다.

**Tech Stack:** Node.js 24 ESM, discord.js 14(기존), Node 내장 `node:test`·`node:child_process`·`node:vm`(기존 격리 구조), 추가 의존성 없음.

**Spec:** `specs/2026-09-06-specup-efficiency-design.md` (이하 "스펙"). 절 번호는 스펙 기준.

## Global Constraints

- 새 npm 의존성 추가 금지. 새 환경변수·포트·권한 없음(스펙 6절).
- 로펙 코드 실행은 기존 격리 그대로: `--permission`, harden 파일만 읽기, 코드 생성 금지, `--max-old-space-size=256`, `LOPEC_SANDBOX_WRAPPER`(B안). 시세는 JSON 직렬화로만 주입, 결과 JSON 1MB 상한(스펙 6절).
- 격리 시간 상한: 스펙업만 20초, 기존 팔찌·아크그리드는 15초 유지. 격리 프로세스 동시 실행 2개 상한(스펙 6절).
- 캐시는 모두 메모리: 결과 캐릭터당 5분, 시세 전역 5분, 로펙 페이지·모듈 묶음 기존 5분·배포 키(스펙 6절).
- 공식 API: **시세용 ≤ 14회 + 명령의 캐릭터 존재 확인 1회 = 캐릭터당 ≤ 15회**, 5분 내 재호출 0회. 분당 100회는 운영 봇과 공유. 예산·매핑 불명(악세)·실패는 로펙 값 유지(스펙 5절).
- 코어 계약(스펙 4절, Phase 0 반영): `getSpecupGuide(name) → Promise<SpecupGuide | null>`. 실패는 전부 `null`(예외 전파 금지). **2단계 평가** — 로펙 시세로 표시 후보 식별자를 고정(= 로펙 표)하고 우리 시세로 같은 후보의 `costValue`만 재평가. `rows`는 코어가 정렬(`per100k` 내림차순, `null`은 맨 앞, 동률은 증가분 내림차순), 증가분 ≤ 0 제외, `expectedCost` = costValue(0 이상 유한수, 소수 허용), `per100k`는 `number | null`, `priceSource`는 `'api'|'lopec'|'fixed'`, `pricedAt`은 시장 시세 원본 시각의 최소(전부 fixed면 `null`), `priceStale`, JSON에 `Infinity`·`NaN` 금지. **무료 = costValue 0 이고 요구 시세 키 전부 가용**일 때만; 아니면 `droppedForPrice`. 후보 0개는 `rows: []`(정상), 후보가 있었는데 전부 비용 미확인이면 `null`.
- 표시 규칙(스펙 2절): 상위 10개, 점수·증가분·`점수/10만G` 소수 1자리, 비용 천 단위 정수 반올림, 0G 행은 `무료 · —`, 로펙 시세 행은 `*`(`fixed` 행은 `*` 없음), 푸터 7항목 순서 고정·조건부 표시. 반올림·자르기는 표시 계층에서만.
- 카톡 전체 보기 링크: **후보 > 10개 또는 최종 메시지(본문+후속 안내) > 1,500자**면 생성, 둘 다 아닐 때만 생략(스펙 2절·3절).
- 카톡 가독성: 핵심 수치 위, 항목 사이 빈 줄, 공백 정렬 표 금지. 기존 정보·조건 문구 삭제·축약 금지.
- 문구 규칙: 공개 자료에 비공개 운영 정보·비밀값·불필요한 작성 표시를 넣지 않는다. 게시 전 프로젝트의 공개 문서 규칙을 확인한다.
- 브랜치: 기획 담당 `feat/specup`(워크트리 `D:\OpenTalk-specup`), 기술 담당 `feat/specup-core`(워크트리 `D:\OpenTalk-specup-core`, `git worktree add ../OpenTalk-specup-core -b feat/specup-core dev`). 파일 경계는 아래 표. 같은 파일을 양쪽이 만지지 않는다. `git status`에 gitignore 대상인 인수인계 문서 두 개가 보이면 스테이징하지 않는다.
- 테스트 파일은 저장소에 커밋하지 않는다. 기획 담당은 `SCRATCH_P`, 기술 담당은 `%TEMP%/opentalk-specup-*.mjs`에서 `node --test`로 돌린다.

```js
// /스펙업 표시 계층 — 코어(lopec-sim.getSpecupGuide)가 준 SpecupGuide를 디스코드 본문·카톡 미리보기·카톡 전체 평문으로 바꾼다.
// 반올림·상위 N·표기는 전부 여기서만 한다(코어는 원값과 전체 행을 준다 — 스펙 4절).
import { TITLE } from './kakao/layout.js';

export const PREVIEW_COUNT = 10;

const fixed1 = (n) => n.toLocaleString('ko-KR', { minimumFractionDigits: 1, maximumFractionDigits: 1 });
const goldInt = (n) => Math.round(n).toLocaleString('ko-KR');
const signed = (n) => `${n < 0 ? '-' : '+'}${fixed1(Math.abs(n))}`;
const kstClock = (ms) =>
  new Intl.DateTimeFormat('ko-KR', { timeZone: 'Asia/Seoul', hour: '2-digit', minute: '2-digit', hour12: false }).format(new Date(ms));

// 한 행의 표기 조각. 기대 비용 0G(per100k null)는 "무료 · —", 로펙 시세로 보충한 행은 끝에 *.
export function rowParts(row, baseScore) {
  const free = row.per100k === null || row.expectedCost === 0;
  return {
    label: `${row.kind} · ${row.option}`,
    score: `${fixed1(row.finalScore)} (${signed(row.finalScore - baseScore)})`,
    cost: free ? '무료' : `${goldInt(row.expectedCost)}G`,
    per: free ? '—' : fixed1(row.per100k),
    star: row.priceSource === 'lopec' ? '*' : '',
  };
}

const headerLine = (profile, guide) =>
  `${profile.CharacterClassName} (${profile.ItemAvgLevel}) · 현재 로펙 ${fixed1(guide.baseScore)}`;

const discordLine = (index, row, baseScore) => {
  const p = rowParts(row, baseScore);
  return `${index}. ${p.label}  ${p.score} · ${p.cost} · ${p.per}${p.star}`;
};

const kakaoItem = (index, row, baseScore) => {
  const p = rowParts(row, baseScore);
  return `${index}. ${p.label}\n→ ${p.score} · ${p.cost} · ${p.per}/10만G${p.star}`;
};

export function footerFor(guide) {
  const parts = [
    '점수는 로펙 스펙업 가이드와 동일',
    '비용은 거래소·경매장 실시간 시세(5분 캐시)',
    `시세 기준 ${kstClock(guide.pricedAt)}`,
  ];
  if (guide.rows.some((r) => r.priceSource === 'lopec')) parts.push('* 로펙 시세');
  if (guide.droppedForPrice > 0) parts.push(`시세 미확인 후보 ${guide.droppedForPrice}개 제외`);
  return parts.join(' · ');
}

export function discordDescription(profile, guide) {
  const top = guide.rows.slice(0, PREVIEW_COUNT);
  return [
    headerLine(profile, guide),
    '',
    ...top.map((r, i) => discordLine(i + 1, r, guide.baseScore)),
    '',
    '마지막 열 = 점수/10만G',
  ].join('\n');
}

// 카톡: 미리보기(상위 10개)와 전체(행 전체). 둘 다 제목·머리줄·푸터를 갖춘 완결된 본문이다.
// 행이 10개 이하면 두 문자열이 같아 브리지가 전체 보기 링크를 만들지 않는다(스펙 2절 조건).
export function kakaoTexts(profile, guide) {
  const build = (rows) => [
    `${TITLE(`${profile.CharacterName}님의 스펙업 효율`)}\n${headerLine(profile, guide)}`,
    ...rows.map((r, i) => kakaoItem(i + 1, r, guide.baseScore)),

// 오픈채팅방에 나갈 최종 메시지를 BRIDGE_TEXT_MAX에 맞춘다.
//   body     — 본문(임베드·이미지 URL 등을 편 것)
//   tail     — 뒤에 붙는 후속 안내("▸ 이어서 쓸 수 있어요 …")
//   fullText — 본문과 다른 전체 보기 본문(스펙업처럼 미리보기는 10개, 전체 보기는 전부일 때). 있고 본문과 다르면 링크를 반드시 붙인다.
// 안내는 잘리면 쓸모가 없어지므로 자리를 먼저 빼 두고 본문만 줄인다. 그래서 안내까지 합친 최종 길이가 한도를 지킨다.
export function fitBridgeMessage(body, tail = null, { baseUrl, fullTitle = '조회 결과', fullText = null } = {}) {
  if (!body) return tail || null;
  const reserve = tail ? tail.length + 2 : 0;
  const textMax = Math.max(1, BRIDGE_TEXT_MAX - reserve);
  const fitted = fullText && fullText !== body && baseUrl
    ? fitWithFull(body, fullText, { textMax, baseUrl, fullTitle })
    : fitText(body, { textMax, parts: 1, baseUrl, fullTitle })[0];
  return [fitted, tail].filter(Boolean).join('\n\n');
}

// 전체 보기에는 fullText를 저장하고 링크 줄을 붙인다. 본문이 한도를 넘으면 링크 자리를 빼고 자른다(잘렸으면 MORE_LABEL, 아니면 REST_LABEL).
function fitWithFull(body, fullText, { textMax, baseUrl, fullTitle }) {
  const id = saveResult(fullText, fullTitle);
  const longest = Math.max(MORE_LABEL.length, REST_LABEL.length);
  const room = Math.max(1, textMax - (longest + 1 + `${baseUrl}/p/full/${id}`.length) - 2);
  const parts = splitParts(body, room, 1);
  const chunks = parts.truncated ? dropOrphanHead(parts.chunks, parts.rest) : parts.chunks;
  const kept = chunks.length > 0 ? chunks[0] : '';
  const label = parts.truncated ? MORE_LABEL : REST_LABEL;
  return `${kept}\n\n${label} ${baseUrl}/p/full/${id}`.trim();
}

  return async function execute(interaction) {
    const name = resolveCharacter(interaction);
    if (!name) {
      await interaction.reply(NO_CHARACTER_HINT);
      return;
    }
    await interaction.deferReply();

    // 캐릭터 존재는 코어를 부르기 전에 공식 API로 판별한다 — 코어의 null은 "계산 불가"로만 해석한다(스펙 2절).
    const profile = await getCharacterProfile(name);
    if (!profile) {
      await interaction.editReply(`\`${name}\` — ${NOT_FOUND_HINT}`);
      return;
    }
    const guide = await getSpecupGuide(name);
    if (!guide) {
      await interaction.editReply(`\`${name}\` — ${UNAVAILABLE}`);
      return;
    }
    if (guide.rows.length === 0) {
      await interaction.editReply(`\`${name}\` — ${NO_CANDIDATES}`);
      return;
    }

    const components = characterButtons(profile.CharacterName, FOLLOW_UPS);
    if (interaction.platform === 'kakao') {
      // 미리보기(상위 10개)는 content로, 전체 행은 kakaoFull로 — 브리지가 전체 보기 링크에 후자를 저장한다(스펙 3절 훅)
      const { preview, full } = kakaoTexts(profile, guide);
      await interaction.editReply({ content: preview, kakaoFull: full, components });
      return;
    }

    const embed = new EmbedBuilder()
      .setColor(EMBED_COLOR)
      .setTitle(`❙ ${profile.CharacterName}님의 스펙업 효율`)
      .setThumbnail(profile.CharacterImage ?? null)
      .setDescription(trunc(discordDescription(profile, guide), 4096))
      .setFooter({ text: footerFor(guide) });
    await interaction.editReply({ embeds: [embed], components });
  };
}

export const execute = createExecute({
  getCharacterProfile: fetchProfile,
  getSpecupGuide: (name) => (typeof lopecSim.getSpecupGuide === 'function' ? lopecSim.getSpecupGuide(name) : Promise.resolve(null)),
});

- Produces:
  - `getLopecSnapshots(targets, { now = Date.now, lopec = defaultLopec } = {}) → Promise<{ enhancement: { snapshotId, prices }, auction: { snapshotId, pricesByTarget }, stale: boolean, timeByKey: { [key]: ms } }>`

    — 2단계 평가 ②의 입력. `needs = { materialIds: string[], targets: string[], engravingGrades: { [target]: string } }`.
  - `API_BUDGET = 14`, `MATERIALS`(27종: id → { name, category, perBundleDivisor }), `parseSnapshotTime(snapshotId) → ms|null`

// snapshotId → 원본 시각(ms). ISO 하나, 또는 "multi:ISO,ISO,…"(최소). 못 읽으면 null.
export function parseSnapshotTime(snapshotId) {
  const raw = String(snapshotId ?? '');
  const parts = (raw.startsWith('multi:') ? raw.slice(6).split(',') : [raw]).map((t) => Date.parse(t.trim())).filter(Number.isFinite);
  return parts.length > 0 ? Math.min(...parts) : null;
}

// query 문자열 → 공식 API 호출. 테스트는 fetchers를 통째로 갈아 끼운다.
//   auction:<보석명> · market:<카테고리>:<품명 또는 빈칸>:<등급 또는 페이지>
const defaultFetchers = {
  run: (query) => {
    const [kind, ...rest] = query.split(':');
    if (kind === 'auction') return searchAuctionItems(GEM_CATEGORY, rest.join(':'));
    if (kind === 'market') {
      const [category, name, extra] = [Number(rest[0]), rest.slice(1, -1).join(':'), rest.at(-1)];
      return category === ENGRAVING_CATEGORY
        ? searchMarketItems(category, name, { grade: extra })
        : searchMarketItems(category, name, { page: Number(extra) || 1 });
    }
    return Promise.reject(new Error(`알 수 없는 조회: ${query}`));
  },
};
const defaultLopec = { enhancement: getLopecEnhancementSnapshot, auction: postLopecAuctionPrices };

const apiCache = new Map();   // query → { at, response }
const apiPending = new Map(); // query → Promise<response>  (진행 중 공유 — 실패는 캐시하지 않고 지운다)
const lopecCache = new Map(); // 'enhancement' | 'auction:<정렬 targets>' → { at, value }
const lopecPending = new Map();

function shared(cache, pending, key, now, load) {
  const hit = cache.get(key);
  if (hit && now - hit.at < CACHE_MS) return { promise: Promise.resolve(hit.value), fresh: false };
  if (pending.has(key)) return { promise: pending.get(key), fresh: false };
  const promise = load().then(
    (value) => { cache.set(key, { at: now, value }); pending.delete(key); return value; },
    (err) => { pending.delete(key); throw err; },
  );
  pending.set(key, promise);
  return { promise, fresh: true };
}

// ① 로펙 공개 시세 두 벌. 실패하면 예외(코어가 null로 바꾼다).
export async function getLopecSnapshots(targets, { now = Date.now, lopec = defaultLopec } = {}) {
  const at = now();
  const sorted = [...new Set(targets)].sort();
  const [enh, auc] = await Promise.all([
    shared(lopecCache, lopecPending, 'enhancement', at, () => lopec.enhancement()).promise,
    shared(lopecCache, lopecPending, `auction:${sorted.join(',')}`, at, () => lopec.auction(sorted)).promise,
  ]);
  const timeByKey = {};
  const enhAt = parseSnapshotTime(enh?.snapshot?.snapshotId) ?? at;
  const aucAt = parseSnapshotTime(auc?.snapshot?.snapshotId) ?? at;
  for (const k of Object.keys(enh?.snapshot?.prices ?? {})) timeByKey[k] = enhAt;
  for (const k of Object.keys(auc?.snapshot?.pricesByTarget ?? {})) timeByKey[k] = aucAt;
  return {
    enhancement: { snapshotId: enh?.snapshot?.snapshotId ?? null, prices: { ...(enh?.snapshot?.prices ?? {}) } },
    auction: { snapshotId: auc?.snapshot?.snapshotId ?? null, pricesByTarget: { ...(auc?.snapshot?.pricesByTarget ?? {}) } },
    stale: Boolean(enh?.isStale || auc?.isStale || parseSnapshotTime(enh?.snapshot?.snapshotId) === null || parseSnapshotTime(auc?.snapshot?.snapshotId) === null),
    timeByKey,
  };
}

const positiveMin = (values) => { const v = values.filter((n) => Number.isFinite(n) && n > 0); return v.length > 0 ? Math.min(...v) : null; };
const gemName = (target) => { const [, type, level] = target.split('.'); return `${level}레벨 ${type}의 보석`; };
const engravingName = (target) => target.slice('market.engraving.'.length);

// ② 공식 API로 덮은 스냅샷. 우선순위: 보석 → 각인서 → 재련 재료(카테고리 페이지). 악세는 항상 로펙 값(스펙 5절 v1 정책).
export async function buildSnapshots(needs, lopecSnapshots, { fetchers = defaultFetchers, now = Date.now, budget = API_BUDGET } = {}) {
  const at = now();
  const prices = { ...lopecSnapshots.enhancement.prices };
  const pricesByTarget = { ...lopecSnapshots.auction.pricesByTarget };
  const sourceByKey = {};
  const timeByKey = { ...lopecSnapshots.timeByKey };
  let apiCalls = 0;
  const staleUsed = { value: false };

  const call = async (query) => {
    if (apiCalls >= budget) return null;               // 예산 초과 → 로펙 값 유지
    const { promise, fresh } = shared(apiCache, apiPending, query, at, () => fetchers.run(query));
    if (fresh) apiCalls += 1;
    try { return await promise; } catch (err) { console.error('[스펙업 시세]', query, err.message); return null; }
  };
  const take = (key, value, ok) => {
    if (ok && Number.isFinite(value) && value > 0) { sourceByKey[key] = 'api'; timeByKey[key] = at; return value; }
    return null;
  };

  // 1) 보석
  for (const target of needs.targets.filter((t) => t.startsWith('gem.'))) {
    const res = await call(`auction:${gemName(target)}`);
    const v = take(target, positiveMin((res?.Items ?? []).map((i) => i?.AuctionInfo?.BuyPrice)), res !== null);
    if (v !== null) pricesByTarget[target] = v;
  }
  // 2) 각인서 (후보 metadata의 등급으로 정확 품명 검색)
  for (const target of needs.targets.filter((t) => t.startsWith('market.engraving.'))) {
    const name = engravingName(target);
    const grade = needs.engravingGrades?.[target] ?? '유물';
    const res = await call(`market:${ENGRAVING_CATEGORY}:${name}:${grade}`);
    const item = (res?.Items ?? []).find((i) => i.Name === `${name} 각인서` && (!i.Grade || i.Grade === grade)) ?? (res?.Items ?? []).find((i) => i.Name.startsWith(name));
    const v = take(target, item?.CurrentMinPrice, res !== null);
    if (v !== null) pricesByTarget[target] = v;
  }

// ①(로펙 시세, 후보 고정) · ②(우리 시세, 비용 재평가) · ②의 스냅샷 메타 → 계약(스펙 4절)
function normalizeGuide(phaseA, phaseB, snapshotsB) {
  if (!phaseA || !Number.isFinite(phaseA.baseScore) || !Array.isArray(phaseA.candidates)) return null;
  const base = phaseA.baseScore;
  const byId = new Map((phaseB?.candidates ?? []).map((c) => [c.id, c]));
  const missing = new Set(snapshotsB.missing ?? []);
  const rows = [];
  const usedKeys = new Set();
  let dropped = 0;
  for (const a of phaseA.candidates) {
    if (!Number.isFinite(a.finalScore)) { dropped += 1; continue; }
    if (a.finalScore - base <= 0) continue;                                             // 이득 없는 후보는 추천이 아니다(누락 아님)
    const b = byId.get(a.id);
    if (!b || !b.hasCostModel) { dropped += 1; continue; }                              // ②에서 식별자 미발견 · 비용 모델 없음
    const keys = b.requiredKeys ?? [];
    if (keys.some((k) => missing.has(k))) { dropped += 1; continue; }                   // 요구 시세 키 누락 (cost="0"이어도 무료가 아니다)
    if (!Number.isFinite(b.costValue) || b.costValue < 0) { dropped += 1; continue; }
    const gain = a.finalScore - base;
    const source = b.fixedOnly ? 'fixed' : keys.some((k) => snapshotsB.sourceByKey?.[k] === 'lopec') ? 'lopec' : 'api';
    if (!b.fixedOnly) keys.forEach((k) => usedKeys.add(k));
    rows.push({ kind: String(a.kind), option: String(a.option), finalScore: a.finalScore, expectedCost: b.costValue,
      per100k: b.costValue === 0 ? null : (gain / b.costValue) * 100000, priceSource: source });
  }
  if (rows.length === 0 && phaseA.candidates.length > 0 && dropped > 0) return null;   // 후보는 있었는데 전부 비용 미확인 → 실패
  rows.sort((x, y) => {
    if ((x.per100k === null) !== (y.per100k === null)) return x.per100k === null ? -1 : 1;
    if (x.per100k !== y.per100k) return (y.per100k ?? 0) - (x.per100k ?? 0);
    return (y.finalScore - base) - (x.finalScore - base);
  });
  const times = [...usedKeys].map((k) => snapshotsB.timeByKey?.[k]).filter(Number.isFinite);
  const usedLopec = [...usedKeys].some((k) => snapshotsB.sourceByKey?.[k] === 'lopec');
  return {
    baseScore: base,
    pricedAt: times.length > 0 ? Math.min(...times) : null,
    priceStale: Boolean(usedLopec && snapshotsB.stale),
    droppedForPrice: dropped,
    rows,
  };
}

      const phaseB = await runInSandbox(script, 'specup', JSON.stringify({ parser, options: { ...SPECUP_OPTIONS, enhancementMarketPriceSnapshot: snapshotsB.enhancement, auctionPriceSnapshot: snapshotsB.auction } }), { timeoutMs: SPECUP_TIMEOUT_MS });
      const guide = normalizeGuide(phaseA, phaseB, snapshotsB);
      const lopecRows = guide?.rows.filter((r) => r.priceSource === 'lopec').length ?? 0;
      console.log(`[스펙업] ${characterName} · 행 ${guide?.rows.length ?? 0}개 · 제외 ${guide?.droppedForPrice ?? '-'} · ${((performance.now() - t0) / 1000).toFixed(1)}s · 시세 api ${snapshotsB.apiCalls}회/lopec 행 ${lopecRows}${snapshotsB.stale ? ' · stale' : ''}${snapshotsB.missing.length ? ` · 누락 ${snapshotsB.missing.join(',')}` : ''}`);
      return guide;
    } catch (err) {
      console.error('[스펙업]', characterName, err.message);
      runtime = null;
      return null;
    } finally {
      specupInFlight.delete(characterName);
    }
  })();
  specupInFlight.set(characterName, task);
  task.then((value) => specupCache.set(characterName, { at: Date.now(), value }));
  return task;
}
```
