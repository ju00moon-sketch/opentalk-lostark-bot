# 치적 출처 묶기와 뭉툭한 가시 효과 표시

## 범위

`/치적`의 기존 총합과 합산 기준을 유지하고, 같은 출처의 행을 묶어 표시한다. 뭉툭한 가시 채용 캐릭터에는 노드가 주는 진화형 피해 수치(A안)를 덧붙인다. 미채용 대비 순 딜 변화(B안)는 계산하지 않는다. 조건부 노드·아이덴티티·스킬 한정 효과·파티 시너지는 기존처럼 총합에 넣지 않는다. 각인과 장비의 기존 풀스택 합산, 기습의 대가 채용 시 백 어택 10%는 유지한다.

## 노드 감지와 효과 해석

공식 전투정보실 응답의 `ArkPassive.Effects[]`에서 태그를 제거한 `Description`이 `진화 N티어 뭉툭한 가시 Lv.N`에 맞을 때만 채용으로 판단한다. 레벨은 설명의 값을 사용한다.

같은 항목의 `ToolTip` JSON에 있는 `Element_002`의 `MultiTextBox` 문자열만 읽는다. 태그·줄바꿈·공백을 정리한 뒤 아래 네 문장의 유한한 0 이상 수치를 읽는다. 다른 상자의 다음 레벨 수치와 섞지 않고, 레벨별 고정 표나 임의 기본값을 두지 않는다.

| 항목 | 읽는 문구 |
|---|---|
| 기본 진화형 피해 `base` | 진화형 피해가 X% 증가 |
| 치적 적용 상한 `cap` | 치명타가 발생할 확률이 최대 X% |
| 초과 치적 전환율 `rate` | 초과한 모든 치명타가 발생할 확률의 X%가 진화형 피해로 전환 |
| 노드 진화형 피해 상한 `max` | 이 노드에 의한 진화형 피해는 최대 X% |

치적 상한은 0~100%, 노드 상한은 기본값 이상이어야 한다. 네 값 중 하나라도 없거나 수치가 비정상이면 `⚠️ 뭉툭한 가시 Lv.N 채용중 (효과 수치를 읽지 못해 계산 생략)`만 표시한다.

## 계산

```text
excess = max(0, total - cap)
converted = excess * rate / 100
evo = min(base + converted, max)
```

`total`은 기존 합산값이다. 계산 중 반올림하지 않고 표시는 소수 둘째 자리까지 한다. 상한 해석은 툴팁의 '이 노드에 의한 진화형 피해'를 기본+전환 전체로 보는 보수적 가정이다. 전환분에만 상한을 적용하지 않는다. 총합 120% 이상인 실제 캐릭터를 확인해 이 해석의 재검토가 필요해지면 근거를 남겨 별도로 조정한다.

푸르여우별 고정 예시: 총합 109.04%, 기본 15%, 치적 상한 80%, 전환율 150%, 노드 상한 75%일 때 초과 29.04%, 전환 43.56%, 진화형 피해 +58.56%다. 이 값은 미채용 대비 최종 피해 증가율이 아니다.

## 표시

총합과 출처 행 다음, 기존 추가 치명타 확률 절 앞에 빈 줄과 함께 표시한다. 디스코드 설명과 카톡 평문에 같은 계산 문자열을 사용한다.

```text
⚠️ 뭉툭한 가시 Lv.2 채용중 — 치적은 80.00%까지만 적용
진화형 피해 +58.56% (기본 15.00% + 초과 치적 29.04% × 150% = 43.56%, 노드 상한 75.00%)
```

- 총합이 치적 상한 이하: `진화형 피해 +15.00% (기본, 초과 치적 없음)`.
- 기본+전환이 노드 상한 이상: 상한값과 `상한 도달` 문구, 기본·초과·전환 계산을 표시한다.
- 미채용: 블록을 추가하지 않는다.
- 출처는 기존 등장 순서로 묶고 기존에 표시하던 세부와 중첩 근거를 괄호에 보존한다. 여러 세부가 있으면 각 값도 적는다. 기존 부위별 합산 행은 유지한다.

```text
• 스탯: 49.14% (치명 1373)
• 반지: 1.90%
• 각인: 20.00% (아드레날린 Lv.4)
• 진화: 28.00% (예리한 감각 Lv.2 8.00% · 일격 Lv.2 20.00%)
• 백 어택: 10.00%
```

## 검증과 배포 전제

고정 자료의 109.04%→58.56%, 미채용, 총합 70/80/120/130%, 네 수치 누락·비정상·다른 레벨을 확인한다. 기존 네 캐릭터 기준 총합과 출처 합·세부 보존을 비교하고, 카톡 정식/초성/점 명령과 디스코드 payload를 확인한다. 공개 API 실측이 과거 기준과 다르면 동일 응답을 기존 소스와 새 소스에 넣어 비교하며 자료 시점을 구분한다.

명령 정의 58/61, 환경변수, 의존성, 저장 형식, 폰 필터는 바뀌지 않는다. 재등록이나 데이터 이전이 필요하지 않다. 실제 채팅 발송과 격리·API 조회 검증은 구분한다.
