# 이모티콘 폴더

여기에 이미지를 넣으면 채팅에서 `[파일명` 으로 바로 사용할 수 있습니다.

- 파일명 = 키워드. 예: `따봉.png` → 채팅에 `[따봉` 입력 시 전송
- 지원 형식: png, gif, jpg, jpeg, webp
- 봇 재시작 불필요 — 파일을 넣는 즉시 인식됩니다 (단, 서버에도 업로드해야 실서비스 반영)
- 키워드는 한글/영문/숫자 1~20자만 가능

카카오 링크 카드에서는 전체 그림이 보이도록 가로 2:1 미리보기를 사용합니다. 이미지를 추가하거나 교체한 뒤에는 Python과 Pillow가 있는 개발 환경에서 `python scripts/build-emoticon-previews.py`를 실행하고, 생성된 `assets/emoticon-previews/`를 원본 폴더와 함께 서버에 업로드합니다. 서버에는 이미지 처리 도구를 설치하지 않아도 됩니다. 원본 파일은 바뀌지 않으며 GIF의 애니메이션도 유지됩니다.

파생본이 없거나 원본이 바뀌면 기존처럼 원본 이미지로 표시합니다. 이 경우 새 미리보기를 생성·업로드해야 카드 잘림 방지가 적용됩니다. 새 미리보기는 별도 주소로 전송하지만 이미 보낸 메시지의 카카오 캐시는 남을 수 있으므로 같은 명령으로 새 카드를 보내 확인합니다. 파생 이미지도 공개 저장소에 올리지 않습니다.

⚠️ 다른 봇이나 서비스의 이미지를 무단으로 가져다 쓰지 마세요.
